**How the keys got in.** Foreground `SendInput` with scan codes, sent only while the game window was in front, drives
the game's own menus and throttle. The arrow keys need `KEYEVENTF_EXTENDEDKEY`; without it they arrive as numpad keys
and are ignored. PostMessage reaches only Unity's legacy `Input`, which is enough for F6 (the game must have focus).
This replaces the older note that the game ignores injected keyboard input.
