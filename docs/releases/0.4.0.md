# Art of Sim Rally 0.4.0 — release draft

**Not yet published.** Final capture/replay validation is pending. Stable remains
0.2.7. Do not promote this draft or an earlier candidate as a tested final release.

This version combines the wheel and triple-screen mods under one loader and
adds an optional developer recording/playback package.

- Triple-screen settings are on the Cameras page, with wide-display and
  separate-display layouts. Remove the former separate triple-screen mod when
  installing the unified mod; preserve its configuration for reference.
- Optional **SessionTools** records menu actions, resolved stage/car selections,
  physics poses, original force inputs, requested effects and encoded telemetry.
  It installs separately from the player mod; ordinary play does not record.
- Default playback follows the recorded trajectory with exclusive ownership of
  the player body. It detects competing pose changes and reports incomplete
  playback instead of repeatedly resetting the car.
- Offline analysis checks the original force calculations and supports tuning
  trials without changing game settings. Physical wheel/network output can be
  muted while recording those original signals; replay always mutes it.
- Captures have completion hashes and bounded writers. Replay preserves and
  restores the owner's environment after the game closes. Interrupted or altered
  new-format captures are refused.
- Playback retains the current display layout instead of importing the recorded
  resolution and triple-screen configuration. A stalled Open game bindings
  handoff now returns to Wheel settings after five seconds with recovery help.

The full owner session-5 route and an independent short format-3 capture have
completed trajectory playback. These are specific case results, not a guarantee
of deterministic input physics or every stage/car/restart transition. Original
physics signals, rather than forces generated by kinematic playback, are the
input for force-model comparisons. Native commands do not measure wheel torque.

The optional archive requires the .NET 8 runtime for offline analysis. See
[recording/playback instructions](../SESSION-REPLAY.md) and the
[validation record](../reviews/2026-10-04-playback-validation.md).

Known limits: the reported triple-screen/probe binding handoff (KI-44) has a
bounded-wait recovery fix but still needs its live retest; use the game's
Options → Controls if needed. Hardware-specific
binding/force checks and the complete camera/layout transition matrix remain
open in [Known issues](../KNOWN-ISSUES.md). Existing settings are retained.
