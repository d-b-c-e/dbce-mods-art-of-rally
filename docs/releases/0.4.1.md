# Art of Sim Rally 0.4.1

Camera keys, a crash cue you can feel, and support logging that switches
itself off.

- **Camera keys** use a numpad layout: 8/2 forward/back, 9/3 up/down, 4/6
  left/right, 7/1 tilt down/up, +/- field of view, 5 reset. Each press moves
  one step (default 2 cm, 1° tilt, 2° field of view) and repeats while held.
  The steps are in Advanced → Cameras with a **Default steps** button. Saved
  keys that match the old defaults move to the new layout; keys you changed
  are kept.
- **Crashes** add a short 25 Hz rattle (half the crash strength, 250 ms,
  fading out) to the 120 ms push. Of seven kicks compared on the wheel, this
  one felt most realistic. Wheels that cannot play it get the push alone.
  Crash strength is your saved setting; new installs start at 50.
- **Log detail for support** switches itself off each time the game starts.
- The force feedback log (`%LOCALAPPDATA%\ArtOfSimRally\ffb.log`) is kept
  under 8 MB: a larger one is moved to `ffb.previous.log` at startup.
- The support file lists the game's own steering options (sensitivity,
  deadzone, steer assist, stability assist, steer correction).

Updating: close the game, extract the ZIP into a fresh folder and run its
`Install.bat`. Settings, bindings and triple-screen settings are kept.

Tested by the owner on a MOZA R12 with three 2560x1440 screens. The runtime
code is the 0.4.1-rc.2 candidate the owner drove and approved on October 6;
this archive is the final-labelled build of the same source.

Known limits:

- Button prompts in some menus (for example "next weather") can draw a
  keyboard key and a controller symbol on top of each other, and do not show
  the wheel's button number (KI-46).
- The Open game bindings lock-up reported with separate displays (KI-44) has a
  five-second recovery but no live retest yet; use Options → Controls if needed.
- The optional SessionTools developer package is not part of this release.

See [Known issues](https://github.com/d-b-c-e/dbce-mods-art-of-rally/blob/v0.4.1/docs/KNOWN-ISSUES.md).
