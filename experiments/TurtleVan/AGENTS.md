# Turtle Van experiment

The user authorized building the reference van with a modeled interior and driver
camera on 2026-10-07. Work stays inside this experiment in the existing game repo.
No public publication has been requested.

- This is an original art asset and visual-only development probe. Do not alter
  donor physics, collisions, force feedback, input, assists or scores.
- Preserve the installed ArtOfSimRally payload, settings and native FFB library.
- The original repo's no-cockpit decision applies to stock cars lacking interiors;
  this user-authorized vehicle supplies its own cabin.
- The manual overlay is off at each launch. Since the owner requested a real menu
  choice, selecting a custom entry explicitly activates its cosmetic package. Native
  saves retain the stock donor. Package removal/unloading is a closed-game action.
- Cosmetic Turtle Van is the first deliverable. The later custom-vehicle framework
  and physical handling overrides are a separate development track; do not change
  donor physics as part of the cosmetic release.
- Runtime data is generated by `tools/model.py`. Rebuild it after source changes.
- Run `tools/build.ps1`; inspect exterior and cockpit renders after model edits.
- Keep deployment receipts/backups in ignored `artifacts/`, never commit them.
- Describe Blender renders, mesh validation, game compilation, and in-game acceptance
  separately. Do not mark driving/triples/camera handback tested without observation.
- This development probe does not change the one public mod per game architecture.

Standards audit for this scope: parent adoption has STD-011 through STD-019 unchecked
and STD-002/003/007/008/009 partial. STD-025/026 are absent from its adoption table;
those concern FFB and are outside this visual experiment. This work uses the installed
camera/triple system, introduces no display-topology changes or input bindings, and
keeps its local build/install evidence separate from the main mod's release gates.
